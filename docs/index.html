What Council does

Discover agents on your PATH, run them concurrently on one task, collect independent plans, then challenge the result with a critique pass — including a rotating Devil’s Advocate.

  1. Discover installed AI CLIs and skip the rest.
  2. Plan in parallel — each agent writes its own plan artifact.
  3. Critique anonymized peer plans; one agent plays Devil’s Advocate.
  4. Audit everything under council_runs/ for humans and other agents.

Frequently asked questions

What is AI Council?
A free, open-source CLI that orchestrates multiple AI coding assistants in parallel on one task, then has them critique each other’s plans. It is not a hosted model and does not collect API keys.
Does AI Council require API keys?
No. Council shells out to vendor CLIs you already installed and authenticated (for example claude login).
How do I install AI Council?
Use Homebrew, Scoop, go install github.com/alijamal14/council@latest, or the install scripts in the GitHub repository.
Which AI agents does Council support?
Up to twelve: Gemini, Codex, Claude, Copilot, Cursor, Antigravity, Aider, OpenCode, Qwen, Goose, Amp, and Factory Droid.
Where do Council results go?
Each session writes plan.*.txt, critique.*.txt, label_map.json, and audit.jsonl under council_runs/run_<timestamp>/.
